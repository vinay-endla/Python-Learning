# Python Mini Projects

This folder contains progressively larger projects built while learning Python.

## Purpose

These projects combine multiple Python concepts into practical applications.

Projects will gradually increase in complexity.

## Planned Projects

- Utility Billing System
- Customer Management System
- Smart Meter Analytics
- Electricity Usage Dashboard
- CSV Data Processor
- Utility Report Generator
- AI-powered Billing Assistant
- Energy Consumption Predictor

Each project is designed to reinforce software engineering principles rather than isolated Python syntax.

---

## Engineering Principles

Projects should emphasize:

- Clean architecture
- Readable code
- Separation of concerns
- Maintainability
- Reusability
- Real-world business logic
