# Module 2 - Data Types

## Concepts Learned
- Strings
- Integers
- Floats
- Booleans
- type()

## Key Takeaways
- Python is dynamically typed.
- Strings use quotes.
- Integers have no decimal places.
- Floats represent decimal numbers.
- Booleans are either True or False.

## Real-World Application
Utility systems use:
- String → Customer Name
- Integer → Monthly Usage (kWh)
- Float → Bill Amount ($)
- Boolean → Solar Customer (Yes/No)
