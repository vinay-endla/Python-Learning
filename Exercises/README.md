# Python Exercises

This folder contains coding exercises completed while learning Python.

## Purpose

The goal of these exercises is to strengthen understanding of Python concepts by solving small, focused problems.

Topics include:

- Variables
- Data Types
- Operators
- Conditional Statements
- Loops
- Functions
- Collections
- Object-Oriented Programming
- File Handling
- Error Handling

Each exercise focuses on writing clean, readable, and maintainable code.

---

## Coding Standards

- Use meaningful variable names.
- Follow PEP 8 naming conventions.
- Write readable code before optimizing.
- Add comments only when they improve clarity.
- Test every solution before committing.

---

Exercises are organized as the learning journey progresses.
